## How to Run This Project
1. Ensure you have Python installed.
2. Install the requirements: `pip install -r requirements.txt` (or list your specific libraries like `streamlit` and `pandas`).
3. Run the app: `streamlit run app.py`
4. Upload the `job_trends.csv` dataset if prompted, or ensure it is in the same directory.
